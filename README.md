# ESP32 Mini Smart Home

โปรเจกต์บ้านอัจฉริยะขนาดเล็ก (Smart Home) ควบคุมด้วยบอร์ด ESP32 ร่วมกับแพลตฟอร์ม Blynk IoT โดยมีฟีเจอร์หลักแบ่งเป็น 3 ส่วน ได้แก่ ระบบราวตากผ้าอัตโนมัติ, ระบบไฟส่องสว่างอัตโนมัติ และระบบกันขโมย

## ฟีเจอร์หลัก (Features)

1. **ราวตากผ้าอัตโนมัติ (Automatic Clothesline)**
   - ใช้ **เซ็นเซอร์วัดน้ำฝน (Rain Sensor)** ตรวจจับหยดน้ำ
   - เมื่อฝนตก เซอร์โวมอเตอร์ (Servo) จะดึงราวตากผ้าเก็บอัตโนมัติ
   - เมื่อฝนหยุดตก เซอร์โวมอเตอร์จะกางราวตากผ้าออก
2. **ระบบไฟอัตโนมัติ (Automatic Lighting)**
   - ใช้ **เซ็นเซอร์แสง (LDR / Light Sensor)** ตรวจจับความสว่าง
   - หากสภาพแวดล้อมมืด ไฟ LED จะเปิดโดยอัตโนมัติ
3. **ระบบกันขโมย (Security Alarm)**
   - ใช้ **เซ็นเซอร์ตรวจจับความเคลื่อนไหว (PIR Sensor)**
   - หากตรวจพบความเคลื่อนไหว จะมีเสียงแจ้งเตือนจาก Buzzer

*หมายเหตุ: ทุกระบบสามารถเลือกปรับเป็นโหมด **Manual** เพื่อสั่งเปิด-ปิด อุปกรณ์ต่างๆ ได้ด้วยตนเองผ่านแอปพลิเคชัน Blynk*

## ฮาร์ดแวร์ที่ใช้ (Hardware Requirements)
- บอร์ด ESP32
- Rain Sensor (ขา 13)
- PIR Motion Sensor (ขา 14)
- Light / LDR Sensor (ขา 27)
- Servo Motor (ขา 25)
- LED (ขา 12)
- Buzzer (ขา 26)

## การทำงานกับ Blynk (Blynk Virtual Pins)
| Virtual Pin | หน้าที่ | รูปแบบการทำงาน |
| :---: | :--- | :--- |
| **V0** | เลือกโหมดราวตากผ้า (Auto / Manual) | `1 = Auto`, `0 = Manual` |
| **V1** | ควบคุมราวตากผ้าแบบ Manual | `1 = เก็บ`, `0 = กาง` |
| **V2** | เลือกโหมดเสียงเตือน / กันขโมย (Auto / Manual) | `1 = Auto`, `0 = Manual` |
| **V3** | ควบคุมเสียงเตือน (Buzzer) แบบ Manual | `1 = เปิด`, `0 = ปิด` |
| **V4** | แสดงสถานะการตรวจจับความเคลื่อนไหว (PIR) | อ่านค่าแบบ Real-time |
| **V5** | เลือกโหมดไฟส่องสว่าง (Auto / Manual) | `1 = Auto`, `0 = Manual` |
| **V6** | ควบคุมไฟส่องสว่างแบบ Manual | `1 = เปิด`, `0 = ปิด` |
| **V7** | แสดงสถานะเซ็นเซอร์น้ำฝน | `1 = ฝนตก`, `0 = ปกติ` |
| **V8** | แสดงสถานะเซ็นเซอร์แสง | `1 = มืด`, `0 = สว่าง` |
| **V9** | แสดงสถานะราวตากผ้า | `1 = เก็บ`, `0 = กาง` |
| **V10** | แสดงสถานะหลอดไฟ LED | `1 = เปิด`, `0 = ปิด` |
| **V11** | แสดงสถานะ Buzzer | `1 = ทำงาน`, `0 = หยุด` |

## การใช้งานเบื้องต้น (How to Use)
1. ติดตั้งไลบรารีที่จำเป็นบน Arduino IDE ได้แก่ `WiFi.h`, `BlynkSimpleEsp32.h` และ `ESP32Servo.h`
2. แก้ไขข้อมูลในโค้ดให้ตรงกับระบบของคุณ:
   - `BLYNK_TEMPLATE_ID`, `BLYNK_TEMPLATE_NAME`, `BLYNK_AUTH_TOKEN` (รับจาก Blynk Console)
   - `ssid` และ `pass` (ชื่อและรหัสผ่าน Wi-Fi)
3. อัปโหลดโค้ดลงบอร์ด ESP32
4. เปิดแอปพลิเคชันหรือเว็บเบราว์เซอร์ Blynk เพื่อติดตามสถานะและควบคุมอุปกรณ์ต่างๆ
